# jev-dcm

Discrete-choice diagnostics for Jev-style decision models.

The first research question is intentionally prior to calibration-model design:

> Does a Jev-style neural decision model behave as though its menu-level probabilities are generated by coherent latent preferences?

If not, which choice axioms fail, by how much, and under which kinds of decisions?

## Experiment 00: Menu Geometry

For each controlled state we create five alternatives and evaluate **all 26 menus of size >=2**. We optionally repeat each menu under multiple option orders. From the resulting full choice function we measure:

- option-order sensitivity;
- Luce/MNL independence of irrelevant alternatives (IIA);
- regularity;
- exact distance to the random-utility / random-ranking polytope via a linear program over all `5! = 120` rankings.

This distinguishes three increasingly general hypotheses:

```text
single-temperature softmax / MNL
        ⊂
menu-independent random utility (RUM)
        ⊂
arbitrary contextual neural choice rule
```

A model can violate IIA while still being perfectly rationalizable as a richer RUM. A regularity violation or positive distance to the RUM polytope is therefore more consequential than an IIA violation alone.

## Setup

### 1. Serve Kev with raw logits/probabilities

Kev supports an explicit raw-probability mode. On Apple Silicon its serving path can use MLX automatically.

```bash
git clone https://github.com/jaredpalmer/kev.git
cd kev
uv sync --extra serve
KEV_TEMPERATURE=1.0 uv run --extra serve python -m kev.serve \
  --run jaredpalmer/kev-4b --port 8009
```

`KEV_TEMPERATURE=1.0` is important: the experiment should observe the pointer head before the checkpoint's scalar calibration temperature is applied.

### 2. Install this project

```bash
cd jev-dcm
uv sync --group dev
uv run pytest -q
```

### 3. Run Experiment 00

```bash
uv run jev-dcm exp00 \
  --n-states 20 \
  --permutations 3 \
  --out-dir runs/exp00
```

Or run each stage independently:

```bash
uv run jev-dcm generate --n-states 20 --out data/probes.jsonl
uv run jev-dcm run --input data/probes.jsonl --out runs/exp00/raw.jsonl
uv run jev-dcm analyze --input runs/exp00/raw.jsonl --out-dir runs/exp00
```

## Why start here instead of fitting a better calibrator?

A global temperature assumes the neural scores differ only in a common noise scale. If the model instead exhibits menu dependence, clone effects, order effects, latent abstention, or heterogeneous stochastic regimes, temperature scaling is solving the wrong statistical problem.

Experiment 00 tells us which model class is justified before we introduce heteroskedastic logit, nested logit, latent classes, or an explicit unknown/outside option.

## Next experiments

- **01 — Choice calibration:** fit global-T, heteroskedastic-T, nested-logit, and latent-class calibrators on frozen raw scores.
- **02 — Outside option:** test whether an explicit latent `unknown` state explains binary and multiclass miscalibration.
- **03 — Aggregation/social choice:** treat prompt/order/model perturbations as voters and study aggregation rules only after the single-agent choice function is understood.
